# 🛒 Zepto Website Clone

A **Zepto-inspired grocery shopping website** created using **HTML5 and CSS3**. This project recreates a grocery delivery interface with navigation, categories, product sections, banners, and a detailed footer.

## 🌐 Live Demo

**Live Website:**
https://zepto-projects.vercel.app/

## 📂 GitHub Repository

**GitHub:**
https://github.com/Grishumaniya2104/zepto-projects

## 📌 About the Project

This project is a front-end implementation inspired by the **Zepto grocery delivery website**.

The webpage includes different grocery categories, promotional banners, product cards, prices, ratings, and footer sections. It was created as a practice project to improve **HTML and CSS layout, Flexbox, product card design, and webpage styling skills**.

## 🎨 Product Card Design

Each product uses a product card containing an image and product information.

```html
<section id="products">
```

The product card includes:

```text
Product Image
     ↓
Price + ADD Button
     ↓
Product Name
     ↓
Quantity + Rating
```

A hover effect is also applied to the product image:

```css
.product-details img:hover {
    transform: scale(1.1);
    transition-duration: 1s;
}
```
